# Student Marks Analysis 

## Description
This mini project analyzes student marks using Python.

## Features
- Created dataset using Pandas
- Calculated Mean and Median
- Visualized marks using bar chart

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Insights
- Highest marks are in English
- Average performance is above 80
- Student performs well in ICT and Maths
